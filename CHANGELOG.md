# Changelog

## v0.0.2

### 🇬🇧 English

#### New Feature: Plugin Marketplace

- **Plugin Discovery**: Browse available plugins from multiple sources. Discover new capabilities without leaving the app.
- **One-Click Install**: Install plugins with a single click. Installation runs in the background with real-time progress, no terminal needed.
- **Plugin Management**: Enable, disable, update, and uninstall plugins from a unified management panel.
- **Theme Category**: Dedicated theme browsing tab — filter plugins by theme/UI category to customize the look and feel.
- **Multi-Source Support**: Configure custom plugin sources. Switch between official and community registries without restarting.

---

### 🇨🇳 中文

#### 新功能：插件市场

- **插件发现**：从多个来源浏览可用插件。无需离开应用即可发现新功能。
- **一键安装**：点击即可安装插件。安装过程在后台进行并实时显示进度，无需使用终端。
- **插件管理**：在统一管理面板中启用、禁用、更新和卸载插件。
- **主题分类**：独立的主题浏览标签页 — 按主题/UI 类目筛选插件，快速定制外观风格。
- **多源支持**：配置自定义插件来源。在官方源和社区源之间切换，无需重启应用。
